# Assignment Monitoring System

A web-based Assignment Monitoring System designed to simplify academic workflow for both teachers and students.
Built during our 4th semester project, this platform focuses on reducing assignment chaos by creating a centralized system for task management, submission tracking, grading, and notifications.

## Project Overview

Managing assignments through group chats, emails, and scattered documents often leads to:

* Missed deadlines
* Lost submissions
* Confusion between students and teachers
* Inefficient grading workflows

This project was created to solve these issues with a clean and structured web platform where:

* Teachers can create assignments with deadlines
* Students can track and submit their work
* Email notifications keep everyone updated
* Teachers can review and grade submissions efficiently

## Features

### Teacher Portal

* Create and manage assignments
* Set deadlines for submissions
* One-click grading workflow
* View student submissions
* PDF submission analysis using PyMuPDF
* Automatic email notifications to students

### Student Portal

* Dashboard for all assignments
* Track pending and submitted work
* View deadlines and submission status
* Receive instant email notifications
* Cleaner academic workflow management

### Additional Exploration

* Experimented with Claut-AI for behavioral and workload analysis
* Explored intelligent workload balancing concepts for future improvements

## How It Works

1. Teacher creates an assignment
2. Students receive an email notification
3. Students view assignments from their dashboard
4. Students submit their work before the deadline
5. Teachers review and grade submissions
6. PDF analysis tools assist in evaluation

## Installation

### Clone the Repository

```bash
git clone <your-repository-link>
cd assignment-monitoring-system
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Server

```bash
python manage.py runserver
```
